🛠 Projects Overview:🛡️ NetGuard Network Auditor
A lightweight cybersecurity tool used to audit local networks for vulnerabilities and open ports.

**Key Features:**
Stealth TCP SYN Scanning using Scapy.
Common vulnerability port checking (SSH, SMB, HTTP/S).
Real-time terminal feedback on device security posture.
Tech Stack: Python, Scapy, Socket.

**🚀 Getting Started**
Prerequisites:
Python 3.10 or higher.
Npcap (Required for Windows network packet crafting).
Administrative/Sudo privileges (Required for Network Auditor).
